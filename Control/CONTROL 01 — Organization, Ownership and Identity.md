Version: 0.1
Date: 2026-11-15
Status: Draft
Project: Runtime Republic

---

# 1. Purpose

Defines who owns Runtime Republic, how it is funded, how it speaks, and how its name and GitHub identity are protected.

---

# 2. Core Principle

Runtime Republic provides tools and speaks for no one. People and teams speak for themselves.

---

# 3. Rules

## 3.1 Ownership and funding

1. Runtime Republic is a goodwill project of Lean Office Pro LLC, which owns it and pays its costs.
2. Its purpose is to build an environment where people, teams and organizations organize online, and where software that saves them labor becomes possible.
3. Runtime Republic accepts no money: no donations, dues, grants, sponsorships or payments of any kind.
4. Runtime Republic seeks no tax-exempt status.
5. The website and this repository state: "Runtime Republic is a goodwill project of Lean Office Pro LLC. Free. Accepts no donations." (This follows the funding-disclosure principle of AGCL 00G.)

## 3.2 Speech

1. Every person may form teams, petition officeholders and speak freely. Nothing in Runtime Republic limits that right.
2. Only a team's members speak for their team. No team speaks for another team because they are connected through Runtime Republic.
3. Runtime Republic itself speaks only on issues. It never endorses or opposes a candidate.

## 3.3 GitHub organization

1. One organization, RuntimeRepublic, holds Runtime Republic's repositories. Nobody can create a repository inside it without permission.
2. A separate organization for a place is created only when that place has active members, never to reserve a name. (GitHub prohibits name squatting.)
3. Naming schemes, tried in order; take the first free name:

| Order | Scheme | Example |
|---|---|---|
| 1 | RuntimeRepublic-<place> | RuntimeRepublic-KS |
| 2 | CivicEncounters-<place> | CivicEncounters-KS |
| 3 | BlueprintLiberty-<place> | BlueprintLiberty-KS |
| 4 | RR-<place> | RR-KS |

4. Place codes: US; two-letter state code (KS); county or parish name with "County" or "Parish" spelled out (KS-Sedgwick-County). Names stay within GitHub's 39-character limit (UNVERIFIED).
5. The name actually used is recorded in the registry. The registry, not the name, decides what is official.
6. Verify RuntimeRepublic.com and BlueprintLiberty.com on GitHub so official organizations show a "Verified" badge.

## 3.4 The `level` property

Every repository's `level` is the area it covers: 0-framework, 1-nation, 2-region (state), 3-subregion (county or parish), 4-municipality, 5-special-district. A team's level is the area it covers (Team-America = 1-nation).

---

# 4. Edge Cases

| Case | Handling |
|---|---|
| Someone creates a look-alike organization | Move to the next naming scheme if needed, mark theirs "not official" in the registry and on the website, and report impersonation to GitHub if they pose as Runtime Republic. |
| Someone offers money | Decline. Point them to the organization or team they want to support. |
| A team endorses a candidate | Allowed. The team speaks for itself, not for Runtime Republic or other teams. |
