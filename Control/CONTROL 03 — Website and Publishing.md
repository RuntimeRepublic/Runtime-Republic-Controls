Version: 0.1
Date: 2026-11-15
Status: Draft
Project: Runtime Republic

---

# 1. Purpose

Sets the requirements for Runtime Republic web pages, team join pages, weekly updates and press releases.

---

# 2. Core Principle

Show real progress honestly, and never publish anyone's personal information.

---

# 3. Rules

## 3.1 Join pages (Runtime Republic and every team)

A join page includes:
1. Who we are and how to join.
2. Start learning links.
3. Get ready now steps, and "What GitHub is, and how your information stays safe."
4. "What is shared, and with whom": only you; your team, only when you push it; the public, counts only; no one ever (passwords, Social Security numbers, full account numbers).
5. A link to the cheat-codes page.
6. Where we are: countdown or goal, Latest Wins, this week's wins, checklist, next up, and a link to every week.
7. Latest press release, with a link to past releases.
8. A "working mockup" label until content is final.
9. The funding line from CONTROL 01 §3.1.5. No donate buttons.

Every team also keeps its own social media Page (for example, a Facebook Page).

## 3.2 Weekly updates

1. The Saturday weekly close produces "This week's wins" and moves the previous week to the history page.
2. Latest Wins may be added before Saturday when something worth sharing happens.
3. Counts come from GitHub records only. Unverified numbers are left out.
4. A member's private finances appear only as progress ("dashboard built"), never as amounts, employers or accounts.

## 3.3 Press releases

1. Only the latest press release appears on the join page. All releases are kept, newest first, on a past-releases page.
2. Each release has a date, a headline, a short body, an image saved as images/press/<date>.jpg, and a ready-to-copy post under 280 characters.
3. Check a hashtag on X before using it.

## 3.4 Share posts

After a successful receipt intake, the AI may offer a post under 280 characters that shares the lesson, not the spending, and links to the member's team join page or the Runtime Republic join page.
