# 1. Purpose

Defines how an outside organization becomes a Runtime Republic Qualified Organization, what it keeps, and what Runtime Republic provides.

---

# 2. Core Principle

The organization keeps everything that is its own. Runtime Republic helps it organize online.

---

# 3. Rules

## 3.1 What the organization keeps

Its GitHub organization and repositories, domain, brand, members, leaders and money. Runtime Republic never collects, passes along or shares in any organization's money.

## 3.2 Qualification

1. Its purpose supports a named AGCL control point, cited by document, rule and revision.
2. It publicly states its leaders and its legal form.
3. It follows Runtime Republic data rules for anything it shares through Runtime Republic.
4. It has a Runtime Republic sponsor.
5. It is entered in the registry, Registry/organizations.csv: organization, website, GitHub organization, AGCL point, sponsor, status, approved_on, review_on.
6. Qualification is renewed every year. The organization may leave at any time.
7. Qualification never depends on buying anything (CONTROL 06).
8. The founder approves qualification, for now.

## 3.3 What Runtime Republic provides, free

Templates for chapters and join pages, the Gov data repositories, office hours, a directory listing whose badge links back to the registry entry, AI setup guides, and a path for its chapters to become teams linked back to Team America.

## 3.4 Status values

applicant, qualified, paused, withdrawn, not-official.

# 5. Edge Cases

| Case | Handling |
|---|---|
| A qualified organization lobbies or rallies | Allowed. It speaks for itself. |
| An organization's purpose drifts from its AGCL point | Paused at renewal until resolved. |
| An organization claims qualification it doesn't have | Mark it not-official in the registry and on the website. |
